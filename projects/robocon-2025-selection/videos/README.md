# ROBOCON 2025 校内选拔赛

**实车演示与开发记录 · 8 段视频**

10 人团队合作制作两台机器人。本人负责其中一台车辆的外设驱动、电机控制与整车电控调试；重点演示均为本人负责的车辆，其余收录团队另一台车及早期装置测试。
